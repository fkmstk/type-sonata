# TYPE SONATA — ちいさな おんがくしつ

未就学児〜小学1年生を想定した、音で楽しむタイピングゲームです。光るキーを押すたびに、選んだ曲（きらきらぼし・かえるのうた・メリーさんのひつじ・ロンドンばし）が1音ずつ進み、6問を終えるとシールを集められます。

## 子供向けの遊び方

- **1もじ ぽんっ**: まずは大きな ABC と同じキーを1つ探します。全6問。次の回には別の文字が登場します。
- **ことば ぽんぽん**: ねこ・いぬ・ぶた・さかななど16語の絵を見ながら、短い英単語を左から入力します。1回6語。最初の2回は3文字、その後は4文字の語も混ざります。
- **じゆうに ピアノ**: どの英字キーでも音が鳴ります。「おしまい」で終了。12音以上でシールを獲得します。

### 音楽のしくみ

- **伴奏**: 1音ごとにベースと和音（C・F・G7）が「ブン・チャッ」と添えられ、1本指でも曲らしく鳴ります。
- **楽器**: ピアノ／オルゴール／もっきん／ふえ（Web Audio の合成音。音量は楽器間でそろえています）。
- **がくふ**: 弾いている曲が五線とおたまじゃくし、ドレミのひらがな付きで流れます。
- **曲の旅**: 曲の進み具合はラウンドをまたいで保存され、最後まで弾くと「さいごまで ひけた！」の演出と全曲演奏、ホームの★が付きます。
- **リズム**: じゆうにピアノでは、やさしいドラムと C–Am–F–G の伴奏ループに乗せてペンタトニックで弾けます（オン/オフ可、休止中は止まります）。

時間制限やゲームオーバーはありません。間違えても進行・ごほうびは失われません。ミス直後は850msだけ待ち、光るキーを見て再挑戦できます。曲がフレーズの途中で終わった場合は、案内役のピピが最後の音まで弾いて締めくくります。結果画面では、弾いた曲を本来のリズムで聴き返せます。

パソコンは物理キーボードまたは画面のQWERTYキー、スマホは3つの大きな画面キーで遊べます。スマホでも全キー表示に切り替えられます。長押しによる連続入力は無視し、日本語IMEが有効な場合も物理的な英字キーの位置で入力できます。

## 保護者向けの設定

右上の設定から、音量・大文字/小文字・動きを控えめにする設定を変更できます。ブラウザの機械読み上げは使わず、絵・光るキー・ピピの動きで案内します。

設定・選んだ曲・16種類のシールは、このブラウザの `localStorage` に保存します。保存が使えない環境でも、その回のゲームは遊べます。アカウント作成や外部への送信はありません。

`Esc` または「ひとやすみ」で休止します。タブを離れた際も自動で休止し、再開ボタンから続きを遊べます。

## ローカル起動

ビルド不要です。HTML / CSS / Vanilla JS とローカルのSVGだけで動作します。

```sh
python3 -m http.server 8123 --bind 127.0.0.1
# http://127.0.0.1:8123
```

メインの入口は `index.html`。従来の英単語リコール演奏は `concert.html` に保持し、保護者向け設定から移動できます。ピアノ音源は両方で共有しています（カノン風の旋律はクラシックモードで使用）。

## 動作確認

```sh
npm install
npx playwright install chromium webkit
npm run check
npm test
TEST_BROWSERS=chromium,webkit npm test
```

テストは専用のローカルHTTPサーバーと独立したブラウザを起動します。入力・ミス後の待機・休止・6問の完走・再生・設定とシールの保存・スマホ操作・狭い画面・保存/音声非対応時・従来の12語完奏を確認します。Chromiumでは音声波形の出力、減衰、ミュート時の無音も検証します。

スクリーンショットとテスト結果は `output/verification/` に出力します（Git管理外）。`render_game_to_text()` と `advanceTime(ms)` で状態の参照と時間の制御ができます。

実機スピーカーの音量は端末に依存します。子供本人による使いやすさの確認は別途必要です。

## クラシックモード（従来の遊び方）

タッチタイピング × 英単語学習 × ピアノ音ゲー を融合したWebゲーム。

五線譜の上を英単語が流れ、正しくタイプするたびにピアノが鳴ります。
単語ごとにカノン風のコード進行を巡回するので、打鍵がそのまま旋律になります。

## 遊び方

1. レベルを選ぶ(初級 / 中級 / 上級)
2. 単語はまず**日本語の意味だけ**が表示される(スペルは伏せ字)
3. 英語を思い出してタイプしきれば **Memoria!** ボーナス
4. 数秒待つか打ち間違えるとスペルが現れ、写し打ちで練習できる
5. 金色の演奏ラインの近くで打ち切ると **Bravissimo!**(スコア2倍)
6. 打ちそこねると ♪ をひとつ失い、その単語は終演後の**復習リスト**へ
7. 1楽章12語を演奏しきるとリザルトへ。`Esc`で休止、`Shift + F`で全画面

スマホでは画面下の鍵盤キーをタップして演奏します。

- 画面下のキーボードガイドは指ごとに色分けされ、次に打つキーが光ります
- タイプ中は常に日本語の意味が表示され、完成時にフラッシュします
- スコア / コンボ / 正確率 / WPM を常時計測

## 技術

- ビルド不要の静的サイト(HTML / CSS / Vanilla JS)
- ピアノ音源は Web Audio API による加算合成(音声ファイルなし)
- 収録単語:3レベル × 約50語(日本語訳つき)
