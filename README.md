# TYPE ♪ SONATA — 指で奏でる英単語

タッチタイピング × 英単語学習 × ピアノ音ゲー を融合したWebゲーム。

五線譜の上を英単語が流れ、正しくタイプするたびにピアノが鳴ります。
単語ごとにカノン風のコード進行を巡回するので、打鍵がそのまま旋律になります。

## 遊び方

1. レベルを選ぶ(初級 / 中級 / 上級)
2. 流れてくる英単語をホームポジションでタイプ
3. 金色の演奏ラインの近くで打ち切ると **Bravissimo!**(スコア2倍)
4. 打ちそこねると ♪ をひとつ失い、その単語は終演後の**復習リスト**へ

- 画面下のキーボードガイドは指ごとに色分けされ、次に打つキーが光ります
- タイプ中は常に日本語の意味が表示され、完成時にフラッシュします
- スコア / コンボ / 正確率 / WPM を常時計測

## 技術

- ビルド不要の静的サイト(HTML / CSS / Vanilla JS)
- ピアノ音源は Web Audio API による加算合成(音声ファイルなし)
- 収録単語:3レベル × 約50語(日本語訳つき)

## ローカルで動かす

```sh
python3 -m http.server 8123
# → http://localhost:8123
```

## デプロイ

静的サイトなので Vercel にゼロコンフィグでデプロイできます。
